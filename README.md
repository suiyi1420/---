# XAUUSD TradingView 订单流（代理）脚本

在 TradingView 上为 **黄金现货/美元（XAUUSD）** 提供多周期订单流观察与买卖提示。  
本仓库包含两个 Pine Script v5 脚本，可直接复制到 TradingView 使用。

> **重要限制**：TradingView 对多数 XAUUSD 数据源只有 **tick volume**，没有真实买卖盘、成交明细或 Level 2。  
> 这里的「订单流」是用 **K 线几何位置 + 成交量** 估算的 Buy/Sell Volume、Delta、CVD，属于业界常用的代理方案，不是交易所真实 footprint。  
> 延迟是可接受的：默认在 **K 线收盘后确认**，减少重绘。

## 文件

| 文件 | 用途 |
|------|------|
| `pine/OrderFlow_MTF.pine` | 指标：Delta / CVD / 失衡 / 多周期共振 / 买卖提示 |
| `pine/OrderFlow_Strategy.pine` | 策略：同一套逻辑入场，带 ATR 止盈止损与时段过滤 |

## 安装到 TradingView

1. 打开 [TradingView](https://www.tradingview.com/) → 图表选 `XAUUSD`（任选你常用经纪商源）
2. 底部 **Pine 编辑器** → 新建空白指标/策略
3. 清空默认代码，粘贴对应 `.pine` 文件全部内容
4. 点击 **保存** → **添加到图表**
5. 建议：
   - 观察用：先加 `OrderFlow_MTF`（副图）
   - 回测/警报：再加 `OrderFlow_Strategy`（主图）

### 推荐图表周期

| 交易风格 | 图表周期 | 高周期建议（脚本默认） |
|----------|----------|------------------------|
| 短线 | 1m / 3m | 5 / 15 / 60 |
| 日内 | 5m | 15 / 60 / 240 |
| 波段 | 15m / 1H | 60 / 240 / D |

在指标设置里可开关三个高周期。

## 指标读法（OrderFlow_MTF）

- **Delta 柱**：估算主动买 − 主动卖；青绿偏买，红色偏卖
- **Delta SMA**：平滑后的方向
- **CVD**：累计 Delta；价格新高而 CVD 不创新高 → 看跌背离，反之看涨
- **失衡三角**：买/卖量比超过阈值
- **紫色背景**：高量窄振幅 → 可能吸筹/派发
- **BUY / SELL 标签**：多周期同向 +（失衡 或 背离 或 吸筹）时给出提示
- **右上角面板**：各周期偏向与当前 Delta/CVD

### 警报

在图表上对指标创建警报，可选：

- 订单流买入提示 / 卖出提示
- 买失衡 / 卖失衡

## 策略说明（OrderFlow_Strategy）

入场（收盘确认）：

1. 本周期 + 启用的高周期，同向数量 ≥ `最少同向周期数`
2. 且满足其一：失衡 / CVD 背离 / 吸筹派发
3. 可选：只在 `0700-2200`（图表交易所时区）交易欧美活跃段

出场：

- ATR 止损 / 止盈
- 可选浮盈后移至保本
- 多周期偏向翻转时平仓

请先在策略测试器里用你的数据源回测，再考虑实盘警报。

## 参数怎么调（黄金）

1. **失衡阈值**：默认 `1.8`；信号太少可降到 `1.5`，太多可升到 `2.2`
2. **最少同向周期数**：默认 `2`；更保守用 `3`
3. **Delta 平滑**：默认 `3`；越大切换越慢
4. **仅收盘确认**：保持开启，接受 1 根 K 线延迟，换更稳的信号

## 和以前 Python（FiboBrain）的关系

若你之前的系统偏斐波那契结构或回测链路过重，本脚本刻意做成：

- 单一、可观察的订单流代理层
- 多周期共振过滤噪音
- 信号与策略拆开：先看 `OF-MTF`，确认有用再开策略

后续可再叠加：结构位、Session VWAP、亚洲盘高低点突破等，而不要一上来堆太多规则。

## 使用建议

1. 先只看副图 Delta/CVD 是否与价格行为合拍（尤其伦敦开盘后）
2. 打开买卖提示，人工对照 2–4 周图表，再决定是否用策略版
3. 同一品种尽量固定一个数据源（不同经纪商 tick volume 差异大）
4. 实盘前用 TradingView 警报纸交易，不要直接全仓跟信号
