# XAUUSD TradingView 订单流

基于 **Volume Delta / CVD / 多时间级别共振** 的 Pine Script 脚本，用于在 TradingView 观察黄金现货（XAUUSD）订单流，并可选接入买卖策略。

> **重要说明**：TradingView 对 XAUUSD（外汇/CFD）通常没有真实 Level 2 / DOM / 逐笔买卖队列。本方案用「涨跌成交量拆分 + 低周期汇总」近似订单流，可有延迟（默认收盘确认），适合观察与告警，不保证盈利。

## 文件

| 文件 | 用途 |
|------|------|
| `pine/XAUUSD_OrderFlow.pine` | 订单流指标：Delta、CVD、失衡、MTF 面板、买卖提示 |
| `pine/XAUUSD_OrderFlow_Strategy.pine` | 策略：同逻辑自动提示/回测买卖，带 ATR 止损止盈 |

## 在 TradingView 中安装

1. 打开 [TradingView](https://www.tradingview.com/) → 图表 → `XAUUSD`
2. 底部 **Pine 编辑器** → 新建 → 粘贴对应 `.pine` 文件全部内容
3. 点击 **保存** → **添加到图表**
4. 策略脚本用「策略测试器」查看历史表现；指标脚本看副图 Delta/CVD

建议先只加 **指标** 观察 1–2 周，确认方向感后再加 **策略**。

## 推荐图表设置

| 图表周期 | 低周期 LTF | 高周期 HTF1 / HTF2 / HTF3 |
|----------|------------|---------------------------|
| 1m / 3m  | 1          | 5 / 15 / 60               |
| 5m       | 1          | 15 / 60 / 240             |
| 15m      | 1 或 5     | 60 / 240 / D              |
| 1H       | 5 或 15    | 240 / D / W               |

- 勾选 **「仅收盘确认信号」**：有延迟，但信号不闪烁，适合做策略与告警。
- 黄金建议打开策略里的 **伦敦/纽约时段过滤**（默认 UTC 07:00–21:00 近似）。

## 指标怎么读

1. **绿色/红色柱**：当前 K 线净 Delta（主动买 − 主动卖近似）
2. **橙色线**：Delta 均线，柱在均线上方偏多、下方偏空
3. **蓝色 CVD**：累计成交量差；斜率向上=买压积累，向下=卖压积累
4. **右上角 MTF 面板**：图表 + 三个高周期的 Delta 方向是否一致
5. **B / S 标记**：多周期共振 + 失衡/极端 Delta/背离 时的提示

### 信号逻辑（简化）

**买入提示**需同时满足（默认）：

- CVD 斜率向上，且当前 Delta > Delta 均线
- 至少 2 个高周期 Delta 为正
- 出现买方失衡、极端正 Delta，或 CVD 看涨背离之一
- （策略额外）价格在 EMA 上方、处于交易时段

卖出对称。

## 告警

指标 / 策略都内置了 `alertcondition`：

1. 添加到图表后 → 闹钟图标 → 创建告警
2. 条件选本脚本 → 「订单流买入提示」或「策略买入」等
3. 触发频率建议选 **Once Per Bar Close**

## 与旧 Python（FiboBrain）的差异

| | FiboBrain 类 Python | 本 TradingView 方案 |
|--|---------------------|---------------------|
| 数据 | 自接行情/自算 | TV 提供的 volume（黄金多为 tick volume） |
| 订单流 | 可做更细足迹/自研模型 | Delta + LTF 拆分近似 |
| 延迟 | 可自定义 | 默认收盘确认，可关 |
| 策略 | 需自建执行 | 策略脚本 + 告警即可提示 |

若你本地还有 FiboBrain 仓库，可把核心「失衡/CVD」阈值对照本脚本参数（`失衡倍数`、`极端Z`、`最少同向高周期`）做迁移。

## 调参建议

效果差时优先改这些，而不是加更多条件：

1. **最少同向高周期**：`2` → `3`（更少信号、更干净）
2. **失衡倍数**：`2.0` → `2.5~3.0`
3. **极端 Z**：`1.5` → `2.0`
4. 关掉 EMA 过滤先看纯订单流，再决定是否加趋势过滤
