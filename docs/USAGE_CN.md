# 使用步骤（中文）

## 1. 加订单流指标

1. TradingView 打开 `XAUUSD` 图表（建议 5 分钟或 15 分钟）
2. 下方打开 **Pine 编辑器**
3. 粘贴 `pine/XAUUSD_OrderFlow.pine` 全文 → **保存** → **添加到图表**
4. 副图会出现 Delta 柱、CVD 线；右上角有多周期面板

### 参数先这样用

- 用低周期拆分：开
- 低周期：`1`
- 仅收盘确认：开（允许延迟）
- 高周期：`15` / `60` / `240`
- 最少同向高周期数：`2`

## 2. 看懂后再加策略

1. 新建 Pine → 粘贴 `pine/XAUUSD_OrderFlow_Strategy.pine`
2. **添加到图表**（会叠在主图上出 BUY/SELL）
3. 打开 **策略测试器** 看胜率、回撤；不满意先调「最少同向高周期」「失衡倍数」
4. 需要手机/邮件提醒：创建告警 → 条件选策略 → **Once Per Bar Close**

## 3. 常见问题

**Q: 为什么和券商订单流软件不一样？**  
A: TV 上黄金多半是 tick volume，不是真实交易所买卖队列。本脚本是「可交易的近似订单流」。

**Q: LTF 拆分报错或数据不足？**  
A: 把指标里「用低周期拆分」关掉，只用当前周期涨跌拆量；或把图表周期调大、LTF 仍用 `1`。

**Q: 信号太多/太少？**  
A: 太多 → 最少同向高周期改为 3，失衡倍数调到 2.5+；太少 → 改为 1，Z 阈值降到 1.2。

**Q: 可以自动下单吗？**  
A: TradingView 告警可对接 webhook；真正自动下单需你自己的执行端（MT5/券商 API 等），本仓库只提供信号与回测。
